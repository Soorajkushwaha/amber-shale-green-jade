# DesiDiya: Light Up India

A mobile-browser 3D side-scrolling adventure. Ayaan Mehra carries a diya across Indian cities, lighting streets and fighting original darkness creatures. No install.

## Play

```bash
npm install
npm run dev
```

Open the local preview. Desktop: A/D or arrows move, Space jumps, Shift sprints, mouse aims, click or F shoots. Phones get a stick plus Jump, Shoot and Run. Progress stays in this browser.

## Build

```bash
npm run build
npm run preview
```

The game is client-side (local save, no account). The production build is a web app and can be hosted on Vercel or Cloudflare as a static/web deployment of this project.

## Cities

Five regions, twenty cities, then Light Up All India. Gurugram has five hand-built streets. The other cities are playable generated streets with their own palette, landmark and boss. Only the current street is loaded.
